# Inactive contract examples

These files make the plan reviewable. They are **design fixtures, not an accepted runtime format,
working API or executable deployment configuration**. No secret, real provider model, qualified
runtime or authorized GitHub repository is configured.

| File | Purpose |
| --- | --- |
| [company-policy.json](company-policy.json) | Enterprise dimensions with execution and external effects disabled |
| [finding.json](finding.json) | ParcelDesk defect proposal with synthetic evidence and no auto-delivery authority |
| [decision.json](decision.json) | High score + tiny critical change still requires step-up |
| [github-issue-intent.json](github-issue-intent.json) | Preview-only outbox intent and exact reconciliation marker |
| [contracts.md](contracts.md) | Proposed cross-component interface and versioning requirements |

Mandatory repository IDs, approved profiles and runtime evidence are intentionally missing.
A future compiler must reject live admission from these fixtures. Strings prefixed `example:`
are identifiers for examples, not valid signatures, source SHAs, artifact hashes or identity proof.
